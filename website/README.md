# CNX Web 独立展示网站

这是计算器项目的展示页，不是 Casio 官方站点，也不与计算器页面合并。

在工作区根目录运行 `node website/server.mjs`，打开 `http://127.0.0.1:5175/`。该服务仅监听本机，只提供此目录的静态网页资源。

- 原计算器继续使用 `frontend/` 和端口 5173；这里不导入其 JS、不嵌入 iframe、不加载 WASM 或 ROM。
- “开始计算”另开 `http://127.0.0.1:5173/frontend/`。独立部署时，修改 `app.js` 开头的 `calculatorUrl` 为实际计算器地址；计算器服务须另行启动。
- `index.html`、`style.css`、`app.js`、`assets/` 是独立静态站点，可单独托管，无 npm 运行依赖、在线字体、分析脚本或外部组件库。
- 展示机身来自现有研究封面选区，图片未经重绘。来源及权利说明见 `assets/NOTICE.md`；这是有限分辨率的静态展示图，不是可点击的模拟器。
- 首屏只保留产品、一句标题、一个主要行动按钮和三个短标签；项目说明默认折叠，不再展示长段功能介绍与多个宣传区块。
- 动效是一段 6.2 秒的有限入场：机身从画外进入、面板扫光、镜头拉开、屏幕闪亮、标题和按钮依次出现，最终定格。可点击「重播入场」，可关闭，遵循系统减少动态效果；不再循环悬浮或鼠标倾斜。屏幕闪亮是展示光效，不是计算输出。
- 本次没有公开部署。发布前确认机身素材传播权限；展示页不附带 ROM。
