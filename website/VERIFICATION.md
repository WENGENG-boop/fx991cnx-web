# 独立官网验证记录

## 当前呈现

按用户反馈将长介绍页收为一屏核心展示：一个标题、一个首屏主按钮、产品图和三个短标签。详细项目说明默认折叠；不是把计算器嵌进官网。

- `node --check website/app.js` 通过。
- Playwright / Chromium 的 1440×1000、1280×800、390×844、320×568、820×1180、1180×820 六视口通过；无横向溢出，无页面脚本或 HTTP 错误。

## 边界

原机身选区只有 344×720，官网展示不声称获得新的高清细节。环绕光轨是程序生成的几何装饰，不是计算器数据；展示图也不是可操作的模拟器。没有复制 ROM 到此网站，没有上传或公开托管。

手机短屏允许纵向滚动，不能保证整台展示机身在 320×568 首屏里完整呈现；标题和开始按钮优先可见。真实设备、Safari、低性能设备帧率和屏幕阅读器仍需进一步测试。
